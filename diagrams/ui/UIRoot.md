# UIRoot

**类型：** `static class`
**文件：** `Assets/Scripts/StarFramework/UI/Framework/UIRoot.cs`

## 职责

静态 UI 根节点管理器，所有 UI 面板的挂载父节点。

## 静态属性

| 属性 | 用途 |
|------|------|
| `PageRoot` | UIPage 挂载根 |
| `WindowRoot` | UIWindow 挂载根 |
| `WidgetRoot` | UIWidget 挂载根 |
| `TopWidgetRoot` | 顶层 Widget 根 |
| `SystemWidgetRoot` | 系统 Widget 根 |
| `GuideUIRoot` | 新手引导 UI 根 |
