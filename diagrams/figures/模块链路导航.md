# 模块关系导航

> 纯文本导航文档，供 AI 读取模块间的依赖链路。
> 格式：缩进表示层级，→ 表示依赖方向，[] 表示分组。

## 1. 入口与初始化

```
AppMain (Assets/Assets/Scripts/StarGame/AppMain.cs)
├── Prepare.unity 启动场景
├── InitServices()  → 创建全部 Service 单例
├── InitBusiness()  → ModuleManager 创建业务模块
├── 30 FPS 固定逻辑帧
└── 三方组件: DOTween/BestHTTP/Cinemachine/UniTask/Wwise
```

## 2. 架构分层

```
[SGF 框架层] Assets/Scripts/StarFramework/
  ├── Module.Framework/  模块体系

  └── UI.Framework/      UI框架
```

## 9. 网络层

```
SGF.Network 命名空间:
NetworkManager (ServiceModule)  入口
  ├── gameSocket (SocketBase)   系统消息连接
  └── battleSocket (SocketBase) 战斗消息连接 (已废弃)

SocketBase                      Socket 封装
  ├── SocketItem                原生 TCP (connectThread/receiveThread)
  ├── DataBuffer                帧缓冲 (TCP 流 → 完整包)
  └── 重连: 单次3次/总计5次/超时3s

数据流:
  发送: SendMessage → SocketUtils.FormateData → SocketDataPools
        → SocketBase.Send → SocketItem.SendAsync → TCP
  接收: TCP → SocketItem.ReceiveLoop → DataBuffer 组装
        → SocketUtils.Deserialize → [dataType 分流]
        → CustomMsg (ByteStream) or Protobuf (ProtoUtils/PBSerializer)
        → NetworkManager.Update 每帧分发
  MsgEncode  加密/解密
  FixMessageManager  消息分发 (ItemMDMgr/HeroMDMgr/PartnerMDMgr)
  MsgRetManager      回调处理
  CustomMsg          协议号↔类型映射
  CustomMsgID        VerifyReq=1 / HeartBeat=4 / RPCMsg=58
```

依赖链路：`NetworkManager → SocketBase → SocketItem → TCP`
分发链路：`TCP → SocketItem → NetworkManager.Update → FixMessageManager/MsgRetManager → 业务模块`

## 11. 模块系统通信

```
三种通信机制:
  SendMessage(target, func, args)    反射调用, 支持消息缓存
  Event(target, type)                事件订阅, 支持预监听
  GlobalEvent                        全局广播 (跨模块/跨层)

Lua 模块通信:
  C# → Lua: LuaModule.OnModuleMessageEvent
  Lua → C#: LuaCallModuleManager.Event / LuaEventTable
  Lua ↔ Lua: 事件表 / GlobalEvent
```
