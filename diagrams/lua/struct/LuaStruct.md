# Lua 数据结构

位置：`Assets/Res/LuaScripts/Struct/`

Lua 侧自定义数据结构，用于模块间数据传递和 UI 渲染。

| 文件 | 用途 |
|------|------|
| `AwardInfo.lua.txt` | 奖励信息 |
| `TaskInfo.lua.txt` | 任务信息 |
| `TaskScrollInfo.lua.txt` | 任务滚动列表信息 |
| `TutorialItem.lua.txt` | 引导项 |
| `PurchaseGoodsInfo.lua.txt` | 购买商品信息 |
| `PurchaseGoodsDetailInfo.lua.txt` | 购买商品详情 |
| `SellGoodsDetailInfo.lua.txt` | 出售商品详情 |
| `SellGridInfo.lua.txt` | 出售格子信息 |
| `SellingInfo.lua.txt` | 出售中信息 |
| `ShoppingInfo.lua.txt` | 购物信息 |
| `PartnerStarRiseDesPanel.lua.txt` | 伙伴升星描述面板 |
| `PartnerStarRiseFinishPanel.lua.txt` | 伙伴升星完成面板 |
| `StructAccessor.lua.txt` | 结构体访问器 |
